### 1. Kind de `Dupla Bool`

O tipo é:

```haskell
data Dupla a = Dupla a [Int]
```

* `Dupla :: * -> *`
* Quando aplicamos `Bool`:

```haskell
Dupla Bool :: *
```

✅ **Resposta:**
`Dupla Bool` tem kind `*` (é um tipo concreto).

---

### 2. Instância de `Functor`

O `Functor` atua sobre o tipo parametrizado `a`:

```haskell
instance Functor Dupla where
    fmap f (Dupla x xs) = Dupla (f x) xs
```

✔ Apenas o primeiro campo é transformado (`a`).
✔ A lista `[Int]` permanece igual.

---

### 3. Tipo da expressão `Dupla '5' [0,1]`

* `'5' :: Char`
* `[0,1] :: [Int]`

Então:

```haskell
Dupla '5' [0,1] :: Dupla Char
```

✅ **Resposta:** `Dupla Char`

---

### 4. Tipo da expressão `Dupla`

`Dupla` é um construtor de dados:

```haskell
Dupla :: a -> [Int] -> Dupla a
```

✅ **Resposta:** `a -> [Int] -> Dupla a`

---

### 5. Instância de `Show`

Queremos exibir como uma tupla `(a,[Int])`:

```haskell
instance Show a => Show (Dupla a) where
    show (Dupla x xs) = "(" ++ show x ++ "," ++ show xs ++ ")"
```

✔ Exemplo:

```haskell
Dupla 'k' [1,2,3]  --> "(\'k\',[1,2,3])"
```

---

### 6. Função `mostra`

Se a lista não for vazia → retorna `Left [Int]`
Se for vazia → retorna `Right a`

```haskell
mostra :: Dupla a -> Either [Int] a
mostra (Dupla x xs)
    | null xs   = Right x
    | otherwise = Left xs
```

---

### ✔ Resumo

* `Dupla Bool :: *`
* `Functor` atua só no primeiro campo
* `Dupla '5' [0,1] :: Dupla Char`
* `Dupla :: a -> [Int] -> Dupla a`
* `Show` imprime como `(a,[Int])`
* `mostra` usa `Either` para decidir o retorno
