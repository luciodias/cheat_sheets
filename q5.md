Aqui estão as definições completas para as funções, respeitando as assinaturas de tipo fornecidas e utilizando a lógica polimórfica do Haskell:

### f1: Reordenando e duplicando elementos
Esta função desestrutura a tupla de entrada e reorganiza os elementos conforme a tripla de saída.
```haskell
f1 :: (a,b) -> (b,a,a)
f1 (x, y) = (y, x, x)
```

---

### f2: Criando uma tupla com o tipo unitário
Aqui, o valor `a` é repetido e o construtor `()` (da unidade) é adicionado ao final.
```haskell
f2 :: a -> (a,a,a,())
f2 a = (a, a, a, ())
```

---

### f3: Conversão de Either para Maybe
Como `Either` representa uma escolha e `Maybe` representa um valor opcional, mapeamos o conteúdo de `a` para `Just` e o valor unitário para `Nothing`.
```haskell
f3 :: Either a () -> Maybe a
f3 (Left x)  = Just x
f3 (Right ()) = Nothing
```

---

### f4: Composição de funções
Esta é a implementação manual do operador de composição `(.)`. Ela recebe uma função que leva de `a` para `b`, outra de `b` para `z`, e retorna uma função que vai direto de `a` para `z`.
```haskell
f4 :: (a -> b) -> (b -> z) -> (a -> z)
f4 f g = \x -> g (f x)
-- Também poderia ser escrito como: f4 f g = g . f
```

---

### f5: Aplicando uma função ao segundo elemento de uma tupla
Esta função (frequentemente chamada de `second` em bibliotecas como `Control.Arrow`) aplica a função `g` apenas ao segundo membro do par, mantendo o primeiro intacto.
```haskell
f5 :: (a -> b) -> (c,a) -> (c,b)
f5 g = \(c, a) -> (c, g a)
```
